# Indonesia BPJS & PPh 21 for Odoo 20 (Sellable Version)

## Features
- Employee PTKP status, BPJS risk class, NPWP
- Full BPJS calculation (JHT, JP with cap, JKK by class, JKM, Kesehatan with cap)
- PPh 21 TER (Categories A/B/C) based on PMK 168/2023
- **Settings page** to change rates and caps without code changes
- Sample salary rules
- Proper Apps description page (`static/description/index.html`)

## Installation
1. Place the folder in your Odoo addons path.
2. Update Apps List.
3. Install the module.
4. Go to Settings → Indonesia Payroll to adjust rates if needed.
5. Fill PTKP & BPJS data on employees.
6. Add salary rules to your payroll structure.
